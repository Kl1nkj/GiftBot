# Что нового в GiftBot

## 1.0.0
- Приложение для Windows: окно, значок в трее, запуск вместе с Windows, журнал бота.
- Обновление в один клик с GitHub — настройки, фильтры и вход в Telegram сохраняются.
- Реальные продажи модели (Portals, Tonnel, блокчейн через MarketApp) и оценка Telegram в анализе.
- Кнопка «Модель: в продаже, сделки, график».
- Новые площадки: MarketApp, GetGems; GRAM понимается как TON.
