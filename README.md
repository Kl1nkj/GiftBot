# Бот-мониторинг подарков

Следит за новыми лотами на площадках и присылает в Telegram подарки, подходящие под ваши фильтры.

| Площадка | Что нужно |
|---|---|
| Portals, Tonnel, Fragment | ничего, работают сразу |
| Telegram Market (официальный), MRKT | API_ID/API_HASH + один раз `python login.py` |
| GetGems | ключ GetGems Public API (`GETGEMS_API_KEY`, https://getgems.io/public-api, 10 GRAM/мес.) |
| MarketApp (лоты в блокчейне) | токен `MARKETAPP_API_TOKEN` (https://marketapp.org/api-token) |

Реальные продажи (за сколько модель действительно купили):

| Откуда | Что нужно |
|---|---|
| Portals, Tonnel — сделки по модели за 30 дней | API_ID/API_HASH + `python login.py` (бот входит в их мини-приложения от вашего имени) |
| Telegram — последняя продажа этого подарка и средняя цена | то же |
| Блокчейн: Fragment, GetGems, MarketApp | `MARKETAPP_API_TOKEN` |

GRAM — это переименованный TON (июнь 2026), курс 1:1; бот понимает обе валюты.

## Запуск

1. Создайте бота у @BotFather и возьмите токен.
2. Скопируйте `.env.example` в `.env` и впишите `BOT_TOKEN`.
3. Установите зависимости и запустите:
   ```
   pip install -r requirements.txt
   python bot.py
   ```
4. Напишите боту /start — он покажет ваш ID. Впишите его в `.env` как `OWNER_ID` и перезапустите бота.
5. Для официального маркета и MRKT: получите API_ID и API_HASH на https://my.telegram.org (API development tools),
   впишите их в `.env` и один раз выполните `python login.py` (номер телефона + код). Появится `user.session` —
   никому его не передавайте, это доступ к вашему аккаунту.

## Мини-приложение

Кнопка «Подарки» слева от поля ввода в боте (или /app) открывает приложение:
- **Лента** — все найденные подарки с картинками, ценой и площадкой; нажатие открывает лот.
- **Фильтры** — создание и редактирование фильтров: выбор коллекций, моделей, фонов и символов из списка
  с картинками, редкостью и флором (данные каталога берутся у Portals), цена, номер, площадки.
- **Площадки** — состояние каждой площадки и пауза уведомлений.

Открыть его может только владелец (OWNER_ID) — бот проверяет подпись Telegram.

Telegram открывает мини-приложения только по https. Домен не нужен — хватит бесплатного адреса DuckDNS:

1. Зайдите на https://www.duckdns.org (вход через Google/GitHub), придумайте имя, например `mygifts`,
   и впишите IP вашего сервера. Получится адрес `mygifts.duckdns.org`.
2. На сервере установите Caddy (он сам получит https-сертификат):
   ```
   sudo apt install -y caddy
   ```
   Замените содержимое `/etc/caddy/Caddyfile` на:
   ```
   mygifts.duckdns.org {
       reverse_proxy 127.0.0.1:8080
   }
   ```
   и выполните `sudo systemctl reload caddy`. Порты 80 и 443 на сервере должны быть открыты.
3. В `.env` впишите `WEBAPP_URL=https://mygifts.duckdns.org` и перезапустите бота.

## Анализ выгодности и охотник за выгодой

К каждому уведомлению бот прикладывает анализ лота:

- **флор модели сейчас** — самые дешёвые другие лоты этой же модели на Portals, Tonnel и Fragment (в уведомлении видно флор каждой площадки);
- **реальные продажи** — сколько раз модель купили за 30 дней, середина и разброс цен, последние сделки;
  если сделок 3 и больше, цена перепродажи берётся не выше их медианы (выставлять можно сколько угодно,
  а покупают — по сделкам);
- **оценка Telegram** — за сколько этот подарок продали в последний раз и средняя цена таких;
- **обычная цена** — медиана цен, по которым модель выставляли за 7 дней (бот копит историю сам,
  первые часы после запуска её ещё нет);
- **коллекция** — флор, средняя цена продажи и число продаж за 24 часа на Portals (ликвидность);
- **перепродажа** — выставить на шаг дешевле самого дешёвого конкурента, минус комиссия площадки
  и перевод между площадками → прибыль в TON и %;
- **пессимистичный сценарий** — прибыль, если продавать по флору коллекции;
- **вердикт**: 🟢 брать / 🟡 есть риски / 🔴 не выгодно, с причинами.

Охотник за выгодой (`/hunt`, вкладка «Выгодно» в приложении) проверяет каждый новый лот, даже без
фильтров, и присылает 🔥 те, что проходят пороги: доходность (по умолчанию 10%), минимальная прибыль
(0.3 TON), максимальная цена лота, только ликвидные коллекции. `/deals` — отчёт по лучшим лотам за сутки.
Кнопка «👀 Модель: в продаже, сделки, график» присылает все такие лоты на площадках, последние сделки
и график: ▲ — сделки, ○ — лоты в продаже по дате выставления, • — цены выставления, которые видел бот.
Кнопка «🔄 Пересчитать» в уведомлении пересчитывает по свежим ценам и проверяет, не купили ли лот.

Комиссии задаются в `.env`: `SELL_FEES=portals:5,tonnel:6,fragment:5`, перевод — `TRANSFER_COST_TON=0.15`.
Цена редких фонов и символов не учитывается — оценка идёт по модели. Это подсказка, а не гарантия:
перед покупкой смотрите карточку сами.

## Команды

- `/app` — открыть мини-приложение
- `/add` — добавить фильтр (текстом, без приложения) (коллекции → модели → фоны → символы → цена → номер → площадки; `-` = любое)
- `/filters` — список фильтров, включить/выключить/удалить
- `/status` — какие площадки работают и когда последний раз опрашивались
- `/pause`, `/resume`

Цена в фильтре — в TON. Лоты официального маркета, выставленные только за звёзды, пересчитываются по `STARS_PER_TON`.
При первом запуске уже выставленные лоты запоминаются молча — уведомления приходят только о новых.

## Приложение для Windows

Ярлык **GiftBot** на рабочем столе (или `pythonw app.pyw`) открывает окно: статус бота, «Запустить/Остановить»,
«Перезапустить», «Настройки» (токен, ID владельцев, ключи площадок — пишутся в `.env`), «Войти в Telegram»,
журнал бота и галочка «Запускать с Windows». Закрытое окно сворачивается в трей — бот продолжает работать.

**Обновления.** Приложение раз в 6 часов проверяет `VERSION` в репозитории GitHub из `update.json`
(`{"repo": "владелец/репозиторий"}`, можно поменять в «Настройках»). Если есть новая версия — кнопка
«Обновить до X»: скачивает код, ставит поверх, при необходимости докачивает библиотеки и перезапускает бота.
`.env`, `data.db`, `user.session` и журналы не трогаются; заменённые файлы копируются в `backup/`.
Выпустить обновление: поднять номер в `VERSION`, описать изменения в `CHANGES.md`, отправить в ветку `main`.

## На своём компьютере (Windows, без сервера)

Если `WEBAPP_URL` пустой и установлен cloudflared (`winget install Cloudflare.cloudflared`),
бот при запуске сам поднимает бесплатный туннель `https://….trycloudflare.com` и ставит его
на кнопку «Подарки». Если Cloudflare недоступен, используется localhost.run через встроенный
в Windows ssh (адрес `https://….lhr.life`). Адрес меняется при каждом перезапуске — старые кнопки в чате перестают
работать, новую даёт `/app`.

- `start_hidden.vbs` — запуск в фоне без окна, с автоперезапуском при падении (лог — `bot.log`).
  Ярлык на него лежит в автозагрузке (`shell:startup`).
- `stop_bot.bat` — остановить бота.
- Компьютер должен быть включён и не спать, иначе лоты за это время пропускаются.

## На сервере (Ubuntu, systemd)

```
sudo apt install -y python3-venv
cd /opt/gift_bot && python3 -m venv venv && venv/bin/pip install -r requirements.txt
venv/bin/python login.py   # если нужен официальный маркет / MRKT
```

`/etc/systemd/system/giftbot.service`:
```
[Unit]
Description=Gift monitor bot
After=network-online.target

[Service]
WorkingDirectory=/opt/gift_bot
ExecStart=/opt/gift_bot/venv/bin/python bot.py
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```
```
sudo systemctl enable --now giftbot
journalctl -u giftbot -f
```
